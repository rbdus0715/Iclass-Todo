# I-Class 할 일 체크 (Chrome 확장)

learn.inha.ac.kr 홈 화면의 강의 카드마다 미시청 영상과 미제출 과제를 배지로 표시합니다.

## 설치
1. Chrome 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 폴더 선택
4. I-Class에 로그인하고 홈 화면 새로고침

## 표시 내용
- 강의 카드 아래 한 줄: `미시청 영상 n`, `미제출 과제 n (D-x)`
- 출석 기간이나 마감이 이미 지난 항목은 표시하지 않음
- 미시청 영상·미제출 과제는 빨간 글씨, 그중 48시간 안에 마감되는 항목은 굵게 표시
- 마감까지 1주일보다 많이 남은 항목은 파란 글씨
- 그 줄을 클릭하면 항목 목록이 펼쳐지고, 항목을 클릭하면 해당 활동으로 이동
- 강의 목록 위 `할 일` 상자: 모든 강의의 할 일을 마감 순으로 모아서 보여줌 (헤더를 누르면 접기·펼치기, 접은 상태는 유지됨)

## 데이터 출처 (강의마다)
- `/report/ubcompletion/user_progress_a.php?id=…`: 영상별 요구시간과 학습시간
- `/course/view.php?id=…`: 영상 학습 기간, 완료 체크 아이콘
- `/mod/assign/index.php?id=…`: 과제 마감일과 제출 상태

결과는 10분 동안 캐시됩니다. 모든 요청은 이미 로그인된 브라우저 안에서만 이루어지고, 외부로 보내는 데이터는 없습니다.

## 문제 해결
F12 → Console에서 `[iclass-check]` 로그를 확인하세요. (기본 필터에서 숨겨지는 **Verbose** 레벨이라 레벨을 켜야 보입니다.)
